|----------|-----------|

# Reporting a Vulnerability

If you discover a security issue affecting this project, please report it privately.

Email:

contact@kellycode.us

Please include:

- Description of the issue
- Steps to reproduce
- Expected behavior
- Potential impact
- Suggested mitigation (if available)
