# Contributing

Thank you for your interest in **KELLY CODE**.

KELLY CODE is an ongoing multidisciplinary research project published by **NVO987**, an international research, culture, and knowledge network operating within the **NEXARIUM** ecosystem.

---

# Scope

Contributions are welcome in areas including:

- Identity theory
- Visual culture
- Art history
- Cultural studies
- Philosophy
- Semantic Web
- Digital humanities
- Research documentation
- Editorial improvements
- Citation corrections
- Accessibility improvements

---

# Before Contributing

Please:

1. Read the README.
2. Review existing Issues and Discussions.
3. Open an Issue before proposing major changes.
4. Keep contributions focused on the project's research objectives.

---

# Pull Requests

Pull requests should:

- be clearly documented;
- contain descriptive commit messages;
- preserve existing citation formats;
- maintain consistent academic language;
- avoid unnecessary formatting changes.

---

# Research Standards

Contributors should:

- provide reliable academic references where appropriate;
- distinguish facts from interpretation;
- avoid plagiarism;
- respect intellectual property;
- maintain scholarly integrity.

---

# Style Guide

Please maintain:

- clear English;
- consistent terminology;
- semantic HTML where applicable;
- accessibility best practices;
- machine-readable metadata whenever possible.

---

# Licensing

Unless explicitly stated otherwise, submitted contributions may become part of the KELLY CODE publication under the repository's license.
