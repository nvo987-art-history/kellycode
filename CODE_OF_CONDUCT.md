# Code of Conduct

## Our Commitment

The KELLY CODE project is committed to fostering an open, respectful, and professional environment for scholarly discussion, cultural research, and interdisciplinary collaboration.

Participation in this project implies acceptance of this Code of Conduct.

---

## Expected Behavior

Participants are encouraged to:

- Treat others with professionalism and respect.
- Support evidence-based discussion.
- Acknowledge differing academic perspectives.
- Cite sources where appropriate.
- Encourage constructive criticism.
- Promote open scientific and cultural dialogue.

---

## Unacceptable Behavior

The following behaviors are not acceptable:

- Personal attacks or harassment.
- Discrimination of any kind.
- Hate speech.
- Defamation.
- Deliberate misinformation.
- Spam or promotional content unrelated to the project.
- Attempts to misrepresent authorship or research findings.

---

## Research Integrity

KELLY CODE is a scholarly research project.

Contributors and readers are expected to:

- Respect intellectual property.
- Avoid plagiarism.
- Preserve proper attribution.
- Distinguish clearly between evidence, interpretation, and opinion.

---

## Scope

This Code of Conduct applies to:

- GitHub repositories
- Documentation
- Issues
- Discussions
- Publications
- Community interactions related to KELLY CODE

---

## Enforcement

Project maintainers reserve the right to remove contributions or restrict participation that violates this Code of Conduct.

Serious or repeated violations may result in permanent exclusion from project spaces.
